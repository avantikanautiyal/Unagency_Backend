# Capability Maturity Model

| Maturity | Intent |
|----------|--------|
| experimental | Early / high review |
| preview | Limited production |
| stable | Default recommended |
| enterprise | Highest bar |
| deprecated | Avoid in new plans |

`nextMaturity()` supports ordered progression experimental → … → enterprise.

Scorecard maturity dimension maps enterprise=1.0 … deprecated=0.15.
