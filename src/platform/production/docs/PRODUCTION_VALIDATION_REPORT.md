# Production Validation Report (Model)

Each `ProductionValidationReport` includes:

- Scenario identity + expectations
- Execution / provider mode
- Validation checks (capability, model, negotiation, routing, runtime, streaming, tools, structured outputs, evaluation, learning, experience, consensus, mesh)
- Benchmark snapshot
- Certification verdicts
- Production readiness score + grade
- Failure analysis (if any)
- Full execution trace
- Selected provider / model / capabilities
- Embedded Integration OS report reference

Generated by `IProductionValidationEngine.validate`.
