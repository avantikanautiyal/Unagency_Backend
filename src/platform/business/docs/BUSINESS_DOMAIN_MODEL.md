# Business Domain Model

| Domain | Responsibilities |
|--------|------------------|
| Organizations | Multi-tenant orgs, ownership, status |
| Departments / Teams | Structure + membership |
| Workspaces / Projects | Isolation + delivery containers |
| Brands | Tone, visual identity, rules, palettes, memory refs |
| Campaigns | Lifecycle, channels, deliverables, analytics tags |
| Assets / Storage | File metadata + storage keys |
| Knowledge | Repositories, versioned documents, search keywords |
| Prompt library | Reusable prompt templates |
| Workflows | Business defs referencing Intelligence workflow refs |
| Executions | Business history + gateway execution linkage |
| Approvals / Collaborators | Reviews, comments, mentions, assignments |
| Notifications / Activity | Feeds and alerts |
| Subscriptions / Billing / Credits | Plans, ledger, invoices (no PSP) |
| Marketplace / Templates | Publishable template metadata |
| Automations / Integrations | Triggers + external connection records |
| Analytics / Audit / Search / Settings | Business metrics and governance |
