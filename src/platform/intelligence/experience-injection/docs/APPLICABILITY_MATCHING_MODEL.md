# Applicability Matching Model

## Rule

Unconstrained fields (undefined) act as wildcards. Constrained experience fields must
equal the corresponding execution context field.

## Dimensions

capability, department, industry, taskType, workflowId, executionStrategy,
promptTemplateId, modelId, providerId, language, organization, workspace,
complexityTier, budgetTier

## Location

`applicability/applicability-matcher.ts`
