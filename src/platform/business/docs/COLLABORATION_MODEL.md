# Collaboration Model

| Primitive | Behavior |
|-----------|----------|
| Comment | On any resource; optional @mentions → notifications |
| Assignment | Assignee notified; activity feed entry |
| Approval | pending → approved/rejected; human-in-the-loop |
| Activity feed | Org-scoped timeline of collaboration + execution events |
| Notification | Per-user inbox |

Campaigns, executions, assets, and documents are first-class collaboration targets.
