# Capability Lifecycle

## States

| State | Meaning |
|-------|---------|
| `draft` | Not ready for planning prominence |
| `active` | Default production taxonomy entry |
| `evolving` | Actively changing; still selectable |
| `frozen` | Stable contract freeze |
| `retired` | End of life |

Helpers: `canEvolve(lifecycle)`.

Lifecycle is independent of maturity but co-reported in maturity reports.
