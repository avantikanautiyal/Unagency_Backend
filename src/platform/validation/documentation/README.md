# Validation Reports

This directory contains production readiness reports generated by the Validation Platform.

## Generation

```typescript
import { setupValidationPlatform, sampleValidationRunRequest } from "../testing";
import { writeReportBundleToDirectory } from "../reports/write-reports";

const { orchestrator } = await setupValidationPlatform();
const bundle = await orchestrator.runWithReports(
  sampleValidationRunRequest({ scenarioIds: ["gateway_e2e", "research_merge"] })
);

if (bundle.ok) {
  writeReportBundleToDirectory(bundle.value, __dirname);
}
```

## Artifacts

| File | Description |
| --- | --- |
| `VALIDATION_REPORT.md` | Overall validation summary |
| `END_TO_END_REPORT.md` | Per-scenario stage results |
| `SECURITY_REPORT.md` | JWT, RBAC, isolation, leakage |
| `LOAD_TEST_REPORT.md` | Load profile metrics |
| `FAILURE_REPORT.md` | Failure simulation catalog |
| `RECOVERY_REPORT.md` | Recovery path validation |
| `PERFORMANCE_REPORT.md` | Latency and throughput |
| `COVERAGE_REPORT.md` | API and module coverage |
| `CERTIFICATION_REPORT.md` | Production readiness score |

Reports are produced by `runWithReports()` — they validate the existing platform without modifying it.
