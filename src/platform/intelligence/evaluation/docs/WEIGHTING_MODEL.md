# Weighting Model

Family weight seeds (normalized to sum 1):

- Marketing: creative 40%, grammar 10%, brand 30%, safety 20% (+ supporting judges)  
- Software: architecture 30%, security 30%, testing 20%, performance 20% (+ …)  
- Healthcare: medical / factual / compliance / safety dominant  

Produces `JudgeWeightProfile` → dynamic `EvaluationRubric` criteria.
